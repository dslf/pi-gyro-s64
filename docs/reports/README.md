# Отчёты шага (docs/reports/)

Публикуемый журнал работ: каждый реализованный шаг фиксируется здесь, чтобы история проекта
читалась вместе с кодом, а не в рабочем scratch (`trash/`, не публикуется).

**Имя файла:** `report_YYYY-MM-DD-<task>.md`, где `<task>` — ID из `Roadmap.md`
 (`E5.T4`, `E6.T7`) или короткое имя задачи, если ID нет.

**Содержание** (по формату `AGENTS.md` §5): цель → что сделано (файлы, функции) → как проверено
(команды и фактические числа) → риски/следующий шаг → статус строки Roadmap. Числа берутся из
вывода команд, не «из головы»; открытые 🔵-решения помечаются явно.

**Правила:** отчёт пишется в том же коммите, что и код шага; существующий отчёт не переписывается
задним числом — правки добавляются новым файлом или комментарием внутри, если решение изменилось.
